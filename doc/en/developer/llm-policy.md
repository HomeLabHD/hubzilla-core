# Policy for generative "AI" use in the Hubzilla project

Contributions to the Hubzilla project must not include content generated, in part or in full, by large language models, diffusion models, or similar deep-learning systems. Content, in this context, includes but is not limited to source code, text, and images in Hubzilla Git repositories, Framagit pull requests, code reviews and comments.

Contributors to the Hubzilla project may use generative AI tools privately to help comprehend, debug, and review the Hubzilla code base and other content, and to do research related to Hubzilla, so long as they do not contribute content generated by such tools to the Hubzilla core or official repositories.

If you feel you need to use generative AI in order to communicate effectively, for example if English is not your primary language, then we would rather you submit issues and patches in your native language. We can use translation tools, or may actually speak enough of your language to communicate, and this way we can be confident that any misunderstanding will be on our part and not on the part of tools you used.

This policy has been adapted for the Hubzilla project from the [Subplot project generative AI policy], and the [OpenJDK Interim Policy on Generative AI].

[Subplot project generative AI policy]: https://subplot.tech/genai/
